# solevia-web

Public website for **Sole Via Entertainment LLC** — served at **https://solevia.app** from
Cloudflare Pages (auto-deploys on every push to `main`; no build step, plain static files).

Kept separate from the app monorepos on purpose: different release cadence and tooling.

## Structure
```
solevia-web/
├── index.html                  # English home        ┐ GENERATED by tools/build.py —
├── pt/index.html               # Portuguese (Brazil) │ edit src/, then rebuild
├── es/index.html               # Spanish (LatAm)     ┘
├── src/
│   ├── index.template.html     # the one home-page template ({{placeholders}})
│   └── i18n/en.json pt.json es.json   # every visible string, per language
├── tools/build.py              # renders the three home pages (Python 3, no dependencies)
├── 404.html                    # Cloudflare Pages serves this for unknown paths
```

## URLs that must keep working
The apps and store listings link to these — never move or delete them:
`/privacy/pop-zen/` · `/terms/pop-zen/` · `/about/pop-zen/` · `/privacy/cap-kickers/` ·
`/terms/cap-kickers/` · `/privacy` (Play listing) · `/app-ads.txt`.

## Languages
The home page exists in English (`/`), Portuguese (`/pt/`) and Spanish (`/es/`), with a
language switch in the header.

- **Default language:** a visitor landing on `/` is sent to the language their browser
  prefers (Portuguese → `/pt/`, Spanish → `/es/`); anything else stays in English.
- **Manual choice wins:** picking a language in the switch is remembered on that device, so
  `/` keeps them in the language they chose.
- **Direct links are respected:** `/pt/` and `/es/` never redirect, so shared links and search
  engines always get the page they asked for (each page declares `hreflang` alternates).

## Legal pages (en · pt-BR · es)
Every game has `/privacy/<slug>/` and `/terms/<slug>/` in English, plus `/pt/privacy/<slug>/`,
`/pt/terms/<slug>/`, `/es/privacy/<slug>/`, `/es/terms/<slug>/`. The English pages are the source;
`python3 tools/build_legal.py` adds hreflang links and the language switch to them and regenerates
the pt/es pages from the hand-written translations inside the script. It fails if an English block
has no translation, so after any English legal edit re-run it and translate the new block.
A new game's pages ship in all three languages (add its slug to `GAMES` in the script).

To change copy: edit `src/i18n/*.json` (or `src/index.template.html` for markup) and run
```bash
python3 tools/build.py
```
The build refuses to run if one language is missing a key that another has.

## Brand
`assets/brand/` holds the Sole Via Entertainment logo — the sun over the horizon with the
winding road (the *via*) leading to it. Use `sole-via-logo.svg` on light backgrounds,
`sole-via-logo-reverse.svg` on dark, `sole-via-mark.svg` where space is tight, and
`sole-via-avatar-1024.png` for social profiles. Text in the SVG lockups is outlined, so they
render the same everywhere.

## Store badges
`assets/badges/` holds the official, unaltered badges downloaded from Apple's Marketing Tools
and Google's Partner Marketing Hub in English, Portuguese (Brazil) and Spanish (LatAm). Keep
them at the same height, don't recolour or crop them, and refresh them from those sources if
Apple or Google update the artwork.

## Updating screenshots
Screenshots live in `assets/img/zen/` and `assets/img/cap/` as 640px-wide WebP.
Zen Bubbles shots are 390×844 @3x captures of the v1.3 web build; Cap Kickers shots are the
v1.2 Play phone set (1080×1920). Keep the file names and the site picks them up. If an
aspect ratio changes, update the `--ar` value on that game's `.phone-screen` in `index.html`.
